## 一、脑机接口（BCI）前沿全景

### 1.1 什么是 BCI
- 脑机接口 = 大脑与外部设备直接通信的通道
- **侵入式**（植入电极，如 Neuralink）· **半侵入**（皮层表面）· **非侵入**（EEG 头环）

### 1.2 2026 产业状态（商业化提速）
- **从实验室 → 规模化落地新阶段**（经济日报 2026-01）
- 应用：医疗康复（瘫痪/渐冻症）· 神经疾病 · 消费（注意力/睡眠）· 军事
- 深圳：**"抢滩万亿级脑机产业新赛道"**（2026 产业报道）

### 1.3 技术路线（2026）
| 路线 | 代表 | 状态 |
|---|---|---|
| **侵入式** | Neuralink（马斯克）· 中国医疗级全植入式 | 临床试验/医疗 |
| **半侵入** | 皮层脑电（ECoG）| 研究/临床 |
| **非侵入** | EEG/脑电帽（消费级）| 已商用 |
| **类脑芯片** | 神经拟态计算 | 研究（河套在采购！）|

### 1.4 关键前沿
- **多模态神经接口**（电 + 光 + 声多模态记录）——河套采购的设备方向！
- 高通量（数千通道）· 无线传输 · 闭环刺激
- **BCI × AI**：解码算法（深度学习读脑信号）——AI 是 BCI 的大脑
- 中国路线："不做马斯克"——自研医疗级全植入式（2026-02 报道）
