## 4. 产品与技术

### 产品线
| 产品 | 发布 | 特点 |
|---|---|---|
| **Even G1** | 2024-06 | 轻量化光波导方案、**同期最轻量产智能眼镜** |
| **Even G2** | 最新旗舰 | **3D 显示 + 戒指交互**、无摄像头、日均佩戴 **8-10h** |

### 核心技术
- **自研光学显示系统 HAO**——关键信息自然呈现在视线内
- **无摄像头方案**——守护隐私（差异化于主流"摄像头+拍摄"路线）
- **钛金属 + 轻量化**——全天候佩戴
- 高端眼镜渠道（400+ 门店、30+ 国）——**眼镜渠道基因**（非科技直营）

### 产品哲学（第一性原理）
> "当行业多数玩家沿用智能手机产品逻辑、不断做加法时，逸文选择回归第一性原理：**人与 AI 之间最自然的交互方式**——保持克制。"

**差异化**：
| 维度 | 主流（Meta 等）| 逸文 |
|---|---|---|
| 摄像头 | 有（拍摄/录像）| **无（隐私优先）** |
| 显示 | 辅助 | **核心（HAO 光学）** |
| 佩戴 | 几小时 | **8-10h（全天）** |
| 渠道 | 科技直营 | **高端眼镜门店** |
| 哲学 | 功能加法 | **克制 + 日常** |

## 5. 市场与赛道

- **市场规模**：2025 全球 $12.58B → 2029 预计 **$138.73B**（艾媒白皮书）
- **爆发逻辑**：光学/结构/芯片拐点 + 大厂入局 + 场景落地
- **华泰观点**：**AI 眼镜 = Agent 时代重要的硬件入口**（Agent 交互终端）
- 竞争：Meta/阿里/华为等生态巨头 + 各类 AI 音频/摄像眼镜

## 6. 前景判断

### 利好
- **赛道爆发**（2029 十倍市场预期）
- **产品差异化**（无摄像头/全天佩戴/眼镜渠道——避开主流红海）
- **团队完整**（苹果制造+光学+眼镜设计+营销）
- **资本认可**（美团/腾讯/红杉——3 年独角兽）
- **日均 8-10h** 佩戴 = 真实用户粘性（品类最高）

### 风险
- 消费电子竞争激烈（巨头入局）
- 眼镜形态的技术天花板（显示/续航/算力）
- 高价（G 系列 ~¥7000）——大众市场渗透待验证
- 硬件迭代快（需要持续融资）

## 7. 对研究的启示（p-research 视角）

1. **Agent 硬件入口**——AI 眼镜是 Agent 时代"信息呈现终端"（与软件 Agent 互补）
2. **产品哲学可借鉴**——"克制 + 日常 + 隐私"vs"功能加法"（第一性原理）
3. **显示优先**——信息自然呈现（与 harness 的"信息可理解"哲学相通）
4. **中国硬件出海**——深圳独角兽，30+ 国
